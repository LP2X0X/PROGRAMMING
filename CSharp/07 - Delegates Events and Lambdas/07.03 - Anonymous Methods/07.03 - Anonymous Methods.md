# Anonymous Methods

Anonymous methods (C# 2.0) let you define inline, unnamed methods using the `delegate` keyword. They are the predecessor to [[Lambda Expression Overview|lambda expressions]] — functionally equivalent, but with more verbose syntax. Under the hood, the compiler generates a hidden method (and a closure class if local variables are captured).
