## Navigation

| Shortcut | Action |
|---|---|
| `Ctrl+P` | Quick Open — jump to any file by name. Use `/` to filter by folder path |
| `Ctrl+Shift+.` | Focus **breadcrumbs** bar — then use Arrow Keys to navigate the path |
| `Ctrl+R` | Quick switch between recent folders/workspaces |
| `Ctrl+Shift+E` | Focus the Explorer sidebar |
| `Ctrl+Tab` | Switch between open editor tabs |
| `Ctrl+\` | Split editor |
| `Ctrl+K Ctrl+O` | Open folder |

### Breadcrumbs Navigation

After pressing `Ctrl+Shift+.`:

| Key | Action |
|---|---|
| Left / Right | Move between path segments |
| Down | Open dropdown showing sibling files/folders |
| Enter | Open the selected item |

If breadcrumbs aren't visible: `View > Show Breadcrumbs` or search "breadcrumbs" in settings (`Ctrl+,`).

## Search

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+F` | Search across all files |
| `Ctrl+G` | Go to line number |
| `Ctrl+Shift+O` | Go to symbol in current file |
| `Ctrl+T` | Go to symbol across workspace |

## Editing

| Shortcut | Action |
|---|---|
| `Alt+Up/Down` | Move line up/down |
| `Shift+Alt+Up/Down` | Copy line up/down |
| `Ctrl+Shift+K` | Delete entire line |
| `Ctrl+D` | Select next occurrence of current word |
| `Ctrl+Shift+L` | Select all occurrences of current word |
| `Ctrl+/` | Toggle line comment |
| `Shift+Alt+A` | Toggle block comment |
| `Ctrl+.` | Quick Fix / code actions |
| `F2` | Rename symbol |
| `F12` | Go to definition |
| `Shift+F12` | Find all references |
